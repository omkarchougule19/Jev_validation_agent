Catch bad chatbot answers before your users see them

AI chatbots sometimes dodge the question, get facts wrong, or return broken data. Jev-Guard checks each answer in about a fifth of a second, fast enough to run on every single reply.

The usual approach is to have a second large AI (like GPT) grade the first one, which is slow and costs money on every message. Jev-Guard uses Jev, a small AI model built only for yes/no and pick-one decisions, to do the same job.

What the verdicts mean

pass Looks fine, safe to show. flag Unsure, worth a human look. block Problem found, don't show it.

If you run several checks, the overall verdict is the worst one.

Does it actually work?

We tested it on 100 made-up answers, some good and some deliberately flawed (including subtle ones like a transposed digit), and compared it with OpenAI's GPT-OSS 120B running on Groq, one of the fastest AI hosts, doing the same checks.

All 100 in a row: Jev 22.4 s, GPT-OSS 41.6 s. GPT-OSS had one false alarm. Against GPT-4o-mini (an earlier run) Jev was about 4× faster at the same accuracy.

The format check is the weakest: small slips like a trailing comma or a missing bracket can get through. For strict JSON, also run a real parser.
